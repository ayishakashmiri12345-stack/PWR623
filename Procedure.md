# How to Submit an Assignment

This part of the guide will describe the steps that every Towson Universty undergrad student must take to sumbit an assignment to blackboard.
## Step 1: Locate Your Assignment

1. Sign in to Towson's Blackboard.
2. Open the Courses page.
3. Select the course containing your assignment.
4. Open Course Content.
5. Locate and select your assignment.

## Step 2: Read the Instructions

Before submitting your work:

1. Read the assignment description.
2. Check the due date.
3. Identify the required file format.
4. Check whether your instructor allows multiple attempts.

## Step 3: Attach Your File

1. Open the assignment submission area.
2. Select the available file attachment option.
3. Find your completed assignment on your computer.
4. Select the correct file and upload it.
5. Verify that the correct filename appears.

[Insert screenshot showing the file attachment option.]

## Step 4: Submit Your Assignment

1. Review your attached file.
2. Check that you selected the correct assignment.
3. Select Submit.
4. Wait for Blackboard to process your submission.

Do not close your browser before the submission is complete.

## Step 5: Confirm Your Submission

1. Check for a submission confirmation.
2. Review the submitted assignment or submission history, if available.
3. Verify that the correct file was submitted.
4. Save any available submission receipt.

If you cannot confirm your submission, see the troubleshooting page.
